🎬 MPV Player Optimized Settings

For zero-lag hardware decoding and stable high-bitrate streaming (e.g. 4K HEVC), we recommend using the external MPV Player.

To optimize MPV for IPTV streaming, copy the configuration below and append it to your mpv.conf file:

  • Linux: ~/.config/mpv/mpv.conf
  • Windows: %APPDATA%/mpv/mpv.conf
# ====================================================================
# --- Core IPTV Buffering ---
# ====================================================================
cache=yes
demuxer-seekable-cache=yes
# Allocate 1GB for historical timeshifting (backwards seek)
demuxer-max-back-bytes=1000M
# Allocate 1GB for forward buffering (prevents stalling)
demuxer-max-bytes=1000M
# Force mpv to cache up to 2 hours ahead if data is available
demuxer-readahead-secs=7200

# ====================================================================
# --- Stream Stability & Network ---
# ====================================================================
# Prevent mpv from closing the stream if the server hesitates
stream-buffer-size=4MiB
# Set a long timeout for network reconnects (in seconds)
network-timeout=60
# Automatically attempt to reconnect if the network drops
rtsp-transport=tcp
# Force the demuxer to thread to prevent UI freezing
demuxer-thread=yes

# ====================================================================
# --- Snappy Seeking & HEVC Video Decoder Fixes ---
# ====================================================================
# Use fast, keyframe-based seeking instead of precise, slow seeking
hr-seek=no

# Allow aggressive frame dropping during a seek to force immediate AV sync
hr-seek-framedrop=yes

# Offload HEVC decoding to the GPU to jump past broken references instantly
hwdec=auto-safe

# Prioritize decoding speed over strict error correction
vd-lavc-fast=yes

# Utilize all available CPU threads as a backup software decoder fallback
vd-lavc-threads=0

# prevent exact seeking when using the on screen position bar with the mouse
script-opts=osc-seekbarkeyframes=yes
📅 EPG Timeshift & Catch-Up

Timeshift (Catch-Up): Allows playing past programs directly from the TV guide. Program blocks that support timeshift are marked with an archive icon or direct badge in the guide.

Automatic EPG Sync: When you select a channel in the sidebar list, the app retrieves its full 7-day past catch-up schedule from the IPTV provider and stores it locally in the database. This allows the EPG Grid to backpopulate with historical data.

⚡ Audio Transcoding Proxy

Chromium does not natively support AC3 / E-AC3 (Dolby Digital) audio formats. Beamcast IPTV solves this by running a background transcoding proxy.

When you start a stream, the app automatically detects if audio transcoding is required and uses system-wide FFmpeg to transcode audio to standard AAC on-the-fly while copying the video stream with zero CPU overhead.
